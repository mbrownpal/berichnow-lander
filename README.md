# Be Rich Now - Landing Page

Static landing page with Kit email form.

## Setup

1. Add `KIT_API_SECRET` to Vercel environment variables
2. Deploy to Vercel

## Structure

- `public/index.html` - Landing page
- `public/be-rich-now-cover.jpeg` - Book cover image
- `api/subscribe.js` - Vercel serverless function for Kit API

Deploys automatically from `main` branch.
